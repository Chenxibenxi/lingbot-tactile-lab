# 下一阶段：从能执行动作到能用视觉触觉修正动作

## 目标和边界

目标是在固定双臂、胸前与腕部相机不变的条件下，训练真正的视觉—触觉—语言动作模型：视觉、触觉、本体并行参与，能定位、建立接触、保持和恢复，在新位置、新物体与任务上泛化。先把单任务学会，再进入20任务循环SFT，最后用严格对照回答触觉何时、如何贡献。不是追求漂亮力曲线，也不是由外部控制器替模型完成任务。

当前保留14维3步0.85加权集成，不再加控制补丁；原物理检查保持。以下是分阶段计划，不是新训练/采集启动通知。Kimi/DS继续暂停。所有试验输出正负结果、失败原因、版本SHA及完整模型视频和同步力表。

## P0：固定基线与数据分区（本次完成记录）

冻结epoch138权重、推理配置、模型输入/动作单位/平台、成功规则和已使用场景清单。已反复使用的4例及32旧test转为开发用途；后续正式成绩用未被调参消费的位置/物体组合，按根场景分组，不能随机拆8150窗口。保存旧结果，不将停用补丁的成绩混入基线。

## P1：先诊断模型究竟有没有学会示范

第一优先级是同观测预测—标签配对，不增加控制。选取50条训练轨迹的接近、下降、闭合、抬升、保持、释放阶段，以固定采样规则提取代表窗口，并在已有开发位置做同口径分析。用冻结权重、多组固定噪声推理；原始50步预测和最终加权执行口径分别报告。保持动作/观测时刻对齐，不能只看平均loss。

交付四张核心表：
1. 各阶段、左右手、预测距离的关节/夹爪误差和FK位移；首动作与远期动作分开。
2. 位置响应：同位置同观测的预测对示范，不再只比较不同布局均值；固定噪声与重复噪声区分条件响应和采样方差。
3. 持物阶段夹爪输出：示范是否在保持、模型何时开始松开，按raw/fused/effective/actual及接触丢失先后对应。
4. 训练/推理等价性：图像顺序/裁剪缩放、语言、state语义、动作归一化、padding与mask、噪声/时间参数、加载的21个可训练张量SHA及梯度路径。已有窗口审计通过不代替完整数值等价检查。

决策：训练观测也预测不准，先查拟合/接口/模型可更新能力；训练观测准而开发位置不准，优先数据覆盖与视觉条件泛化；离线准而闭环失败，优先示范对偏离状态/阶段切换的覆盖。不能在未区分前直接续训到更多epoch。对右手松开也采用同样分支，避免凭力断点就增加抓紧规则。

建议有界起步：每轨迹7阶段各1个可用窗口，最多350观测×2固定噪声；缺阶段如实报告，不补造。先少量左右技术检查估计吞吐，再冻结完整诊断清单。该建议尚未执行。

## P2：依据P1，只改一个学习因素

若数据/模型接口错误，先做最小修复及逐张量往返验证；旧权重保留，修正后的训练另立版本，不能沿用不兼容状态。

若接口正确但训练点都学不准，先做很小的训练内拟合能力检查，确认动作头能否重现几条完整示范。失败时审计梯度、监督缩放、动作时序与可更新模块；现状视觉/动作专家主体冻结，不能假设仅输出LoRA足够。再选择一个有根据的容量变化（例如动作专家条件层LoRA，或视觉到动作连接层适配），与现有适配方式在相同数据、更新预算和随机种子下比较。不是同时解冻全模型，也不默认修改视觉主干。

若训练点学得准但新位置差，优先增加真实位置/姿态覆盖、接近误差后的修正示范；图像增强必须保持动作标签一致，不能随意平移图像而不校正几何。若闭环偏离后不会恢复，补状态条件恢复分支，而非重复大量理想成功轨迹。

阶段采样可增加接近对准与持物窗口权重，但先核验分布；避免放置/释放信号掩盖保持，也不能只训练保持而忘记最终释放。每次只改变一种因素，保留单任务位置/左右回归。需提出具体训练清单、预算和验收结果后，再恢复新训练。

## P3：把触觉变成有用的动作条件

先检查同步四指法向力代理的可观测性：空夹/有效接触/持物风险能否由现有输入区分；有掩码、有时间，不把峰值当同步均衡，不伪造剪切或扭矩。接触丢失、物体相对滑动与主动放置必须分开标注。

数据应包含相近视觉状态下、因接触状态不同而选择保持/收拢/重定位/释放的真实差异，及同物理根的替代动作后果。仿真真值只做离线标签和评分，不进入在线模型。视觉被遮挡时仍持续取图，触觉和本体补充信息，不规定谁永远主导。

训练候选是动作损失加有时间因果隔离的接触/稳定性辅助目标；是否采用由P1/P2证据决定，不能把辅助分类准确当成动作改善。相同权重的遮蔽/错配输入诊断与匹配预算的重新训练对照分开解释。正式比较至少含视觉+本体、真实触觉融合、同容量错配触觉；控制参数、训练预算与场景固定。触觉输入置零可能分布外，不能单凭置零退化宣布触觉有效。

## P4：达到单任务能力门槛，再进入20任务SFT

沿用用户既定门槛：冻结完整新场景面板、每场景相同重复数，完整抓取—稳定持物—放回的seed宏成功率≥70%，不是每个seed70%，也不要求100%。报告置信区间、左右、阶段和技术中断，不能只报告抓起率或排除拒绝回合。正式测试不用于调参；需要开发时另立面板。

达到后进入20任务循环SFT；不继续为了单任务完美而无限延期。每任务至少50条真实独立成功视频，单活动臂25左25右，双臂任务50条真实协作，不以随机种子或镜像凑数。先完成资产/可达性/接触可观测性与专家能力矩阵；无法支持的任务公开缺口，不拿20条提示词冒充20任务。

恢复数据生产时优先：抓取保持放置、已验证推动、位置/方向改变，再逐步补约束操作、双臂协作、恢复。先修换物体渲染错配、单例全视频审核，再有限扩量；失败保留，不自动成为成功BC。按任务/阶段采样，保存单任务回归，避免长轨迹独占。整epoch保存与W&B逐任务指标保留。

## P5：泛化与研究结论

分别测：已见物体新位置、未见物体/几何、不同物理条件、视觉遮挡、单臂与双臂任务迁移。20任务都参加训练时不能声称未见任务泛化。按根场景/资产族划分，预登记指标和配对统计，不按最佳视频挑结果。

最终证据链应回答：视觉定位是否正确、触觉能否识别接触状态、状态差异是否改变动作、改变是否提升完整任务/恢复，以及代价是多少。推理时仿真暂停不等于真实20Hz在线能力，另报告真实推理延迟与反馈带宽；实时部署是独立工程关卡。

下一项具体工作仅为P1冻结模型的配对诊断。暂不扩大集成网格、不添加控制补丁、不启动新训练或采集。根据诊断结果再确定唯一的下一次训练变更。
