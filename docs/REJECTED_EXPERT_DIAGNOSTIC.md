# Relay rejected expert: separate, non-training diagnostic

To honor the owner's request for failure examples without contaminating expert positives, `src/register_negative_diagnostic.py` reads a *pre-existing relay-only* `lift_pot` seed0 rejected rule-expert trial. The trial's `failure.json` says `planner_ok=false`, `goal_ok=false`, `probe_failed=false`, `accepted_for_training=false`. It has **1,044 contiguous physical telemetry steps**, 77 matched observation/saved-frame markers and 77 private camera pickle cache files, but **zero left and zero right finger contact steps**. The original failed recording has **no HDF5, no expert-success gate and no completion manifest**.

`datasets/negative_diagnostics/relay_liftpot_seed0_planner_rejection.json` is a small SHA-256-bound card for the rejection JSON and same-run raw/obs/frame sidecars. It is deliberately outside `datasets/cards/` (the success-only registry), with `status=quarantined_diagnostic_not_training_or_eval`, `accepted_for_training=false`, `has_validated_rgb_hdf5=false`, and `suitable_as_grasp_failure_example=false`. The validator checks task/seed/episode, source host/role, contiguous physics, frame-to-camera markers and absent success markers. No pickle is deserialized or converted; the private cache and telemetry never enter Git.

**What it proves:** a local scene that initialized and generated a trajectory can still fail in the planning/task-goal stage without finger contact. **What it does not prove:** a robot grabbed and dropped the pot, had a valid image/force imitation target, or provides a positive/negative pair suitable for model fitting. Separately, the preregistered `pick_diverse_bottles` seed100001 failed even earlier with `UnStableError` during scene initialization: no physics, frame or contact trajectory was produced, so it is not a grasp failure either. A truly useful near-contact/empty-grasp counterexample still needs controlled same-scene image+action+physics capture, separate negative-only completion schema, and review before any training use.
