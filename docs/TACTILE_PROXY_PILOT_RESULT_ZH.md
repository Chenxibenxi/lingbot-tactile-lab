# 双瓶触觉小代理一次试训结果：弱对照下降，但不能证明触觉VLA有效

遵守[试前冻结方案](<TACTILE_PROXY_PILOT_PROTOCOL_ZH.md>)，在本机单RTX3090持租约时仅做**一次固定种子590的120步试训**：双瓶v2训练折5实际seed共590个同回合因果样本；验证折只有seed100012共126样本（历史有接触70、无接触56）；**测试seed100009的专家回合未加载**。三路当前RGB固定池化+当前14D状态、下一保存帧专家14D命令；两个相同形状的128→64 MLP按同顺序训练，视觉对照的触觉通道全零，触觉组使用过去5个分箱、掩码和age；同一已训练触觉组再仅在验证折接受固定跨样本过去触觉置乱。用户请求试训不改变公开registry/split/norm的未批准状态；代码不是LingBot-VLA模型或真实已部署触觉adapter。

| 验证折过去接触层 | 样本 | 视觉代理14D MAE | 正确触觉代理14D MAE | 固定跨样本置乱14D MAE | 事后原地保持当前14D命令MAE |
|---|---:|---:|---:|---:|---:|

预注册代理内的配对差：接触层正确触觉减视觉为−0.031408，打乱减正确触觉为+0.104932；无接触层分别+0.003044、+0.141837。**关键反证：事后描述性“照抄当前专家命令”基线在同一验证seed的MAE低一个数量级以上**，证明这个120步小代理尚未学会下一动作预测，不能把“比自己较弱的视觉代理好一点”包装成真正效用；保持基线是本次结果后追加的描述性核对，**不属于试前锁定端点、没有用于调参或重试**。14D维度尺度不同，不能只看合并误差；完整私有报告另列12关节／2夹爪两层指标。跨样本置乱同时改变接触与无接触分布，是强分布外检验而非纯时间错位：其劣化说明网络响应输入变化，**不证明产生可用闭环触觉控制**。

**科研结论：本轮为明确的负结果／管线烟测，不是训练成功。**唯一验证物理seed、相邻帧高度相关、只用成功预筛规则专家、没有实际LingBot前向/反向或正式服务，任务成功率及抗扰动完全未测。真实“触觉有用”的下一步应在**未见的更多物理seed**预先冻结新场景、遮挡/位姿扰动、接触后掉落/重抓和松爪后稳定观察窗；同seed、同预算、同模型资产比较视觉-only／正确触觉／仅过去历史打乱，统计全部成功与失败和独立seed层的成对差，另报告掉落、碰撞和延迟。原双瓶官方位置/高度成功检查不保证松爪稳定，见[奖励风险](<ONLINE_RL_REWARD_RISK_ZH.md>)；仅原场景“又成功一次”不能回答此问题。
