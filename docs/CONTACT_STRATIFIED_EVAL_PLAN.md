# Pre-registered contact-window evaluation — no predictions yet

The validated relay pilot has **518** expert-image/next-command pairs in five actual seeds, but only **123** input windows contain an observed nonzero contact proxy; see `MATCHED_ABLATION_INPUT_AUDIT.md`. The other 395 pairs cannot by themselves discriminate tactile conditioning from a within-history permutation. **No tactile-conditioned VLA checkpoint or controlled prediction file exists, and no performance number is reported here.**

`configs/contact_strata_eval_v1.json` pins the unapproved candidate split SHA and three *same-source* input views: `visual_only`, `tactile`, `permuted_causal_history` (the permutation uses only the observed past). `src/contact_stratified_eval.py` is a CPU-only scorer for future prediction manifests with all three predictions for **every** verified source pair. It revalidates each expert card and actual-seed split, compares the manifest's split SHA and vision-checkpoint SHA, reconstructs the next 14D command label **from the verified source rather than accepting labels from predictions**, and rejects extra/duplicate/missing/nonfinite predictions. Only the current input's observed masked mean/peak load determines `past_contact` versus `no_past_contact`—never a future contact target.

The predeclared endpoint is **per-seed mean absolute next-command error**, then a fold macro-mean by actual independent seed. Report all 14 action dimensions plus 12 arm joints (indices 0–5,7–12) and two grippers (6,13) separately, each for the two input-contact strata and all three matched views. One test seed and one validation seed have no useful generalization error bar; zero model fitting may involve these held-out examples. This imitation endpoint is neither online task success nor a calibrated physical gripper-force metric. A future training/approval review must also record the exact candidate split, preprocessing, base checkpoint SHA, adapter bytes/SHA and prediction provenance; this scorer alone cannot prove models never saw held-out data.
