`configs/contact_strata_eval_v1.json` pins the unapproved candidate split SHA and three *same-source* input views: `visual_only`, `tactile`, `permuted_causal_history` (the permutation uses only the observed past). `src/contact_stratified_eval.py` is a CPU-only scorer for future prediction manifests with all three predictions for **every** verified source pair. It revalidates only the selected frozen v1 expert cards, or for bottle v2 revalidates the separate seven-expert builder with the *same original validation and test physical seeds*; extra cards cannot silently redraw the fold. It compares the manifest's split SHA and vision-checkpoint SHA, reconstructs the next 14D command label **from the verified source rather than accepting labels from predictions**, and rejects extra/duplicate/missing/nonfinite predictions. Only the current input's observed masked mean/peak load determines `past_contact` versus `no_past_contact`—never a future contact target.

The predeclared endpoint is **per-seed mean absolute next-command error**, then a fold macro-mean by actual independent seed. Report all 14 action dimensions plus 12 arm joints (indices 0–5,7–12) and two grippers (6,13) separately, each for the two input-contact strata and all three matched views. One test seed and one validation seed have no useful generalization error bar; zero model fitting may involve these held-out examples. This imitation endpoint is neither online task success nor a calibrated physical gripper-force metric. A future training/approval review must also record the exact candidate split, preprocessing, base checkpoint SHA, adapter bytes/SHA and prediction provenance; this scorer alone cannot prove models never saw held-out data, nor authenticate the model bytes behind a caller-supplied SHA. Output explicitly marks `model_artifacts_revalidated=false`: synthetic fixtures can test the scoring formula but must **never** be reported as a real visual-versus-tactile gain.
