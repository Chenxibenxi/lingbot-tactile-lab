# 双瓶最小触觉信息试训预登记（仅探索性代理，不是LingBot-VLA训练）

**本文件在运行试训之前锁定选择**：用户明确要求尝试训练并询问原任务已成功如何证明有效。我们先测试触觉是否为“下一帧专家14维命令”带来可重复的额外预测信息，而**不把这个小代理模型冒充已训练的 LingBot-VLA、机器人闭环成功或稳定放置**。原视觉模型参数、RoboTwin源、公开候选registry/split/norm批准标志均不改，所有输出仅在本机Git忽略目录。用单张本机RTX3090先租约、限时最多20分钟；不能取得租约、显存不足或GPU被Strata/他人占用则不跑。

1. **数据与折**：双瓶旧冻结v1训练seed100000/100002/100007，新增seed100013/100015只在独立v2训练折，共590对；唯一验证seed100012有126对；测试seed100009绝不加载、不得用来调参/选模。逐条仍需本机成功专家源SHA与同回合RGB/接触/下一14D指令同源重验，禁止旧LXC、自回放、受控失败入监督。RGB三摄相同固定池化、当前14D状态、仅当前拍照步之前五个触觉分箱；所有数值归一化仅根据训练折。
2. **控制变量**：固定一次随机种子、训练样本顺序、网络宽度、120个优化步和预设学习率。视觉代理与触觉代理拥有**相同输入维度与可训练结构**；视觉臂仅把触觉通道置零（保留有效视觉+状态及参数路径，不能通过adapter的`enabled=False`早退跳过训练），触觉臂读真实过去触觉。两臂训练在同一批专家RGB/状态/标签上。第三个反证只在验证时，使用已训练触觉代理且以固定置换把不同验证样本的**过去**触觉互换，绝不读未来接触；这不是第三次训练。
3. **事先定义的指标**：只在验证折按`past_contact`（先前接触）/`no_past_contact`分别报告样本数、下一专家命令14D MAE，以及12个手臂关节和2个夹爪维度MAE；以同126个观测逐对比较触觉减视觉、置乱减正确触觉的误差。不能把126个相邻帧当126个独立场景；只有1个验证实际seed，无可信泛化置信区间，不能仅凭一次数值较好就宣称触觉提高了真实任务成功率。若两臂模型容量/输入通道数未做到完全一致，须额外披露且不做因果增益声明。
4. **停止/负结果**：任何跨折、源SHA不符、候选norm误装入正式适配器、无GPU租约、显存超限、非有限损失、测试seed被读取、基线文件被改、模型产物进入Git即停止。即便触觉验证MAE下降，若打乱过去触觉不使性能退化或优势只出现在无接触窗口，优先报告“无证据模型在利用触觉”；反之也只报告**单验证seed离线探索性提示**。真实模型部署须另行获批并重新训练、持久记录权重SHA/训练折和正式服务能力门。
5. **解决天花板效应的后续正式评价（不是本轮试训）**：原任务选中过的视觉基座seed100048已有1/1成功，不能再凭原场景一次成功说触觉有效。应预先固定多个**未见真实seed**与更难但可复现的起始偏移/遮挡/接触丢失/释放后扰动；同seed同预算配对视觉-only与触觉，全部尝试包含初始化与规划失败。除官方成功率外，额外独立报告放开夹爪后固定观察窗稳定落座、掉落/重抓恢复、接触后成功、碰撞异常和延迟。原双瓶官方判据仅瓶位姿/高度且可握瓶刷成功，见[奖励风险](<ONLINE_RL_REWARD_RISK_ZH.md>)。即使离线MAE改进，也**不能代替闭环对照**。
