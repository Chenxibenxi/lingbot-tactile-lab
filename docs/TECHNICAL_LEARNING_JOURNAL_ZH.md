# 中文技术学习日志：从同源触觉数据到独立闭环验证

更新日期：2026-11-07。本文记录截至本次归档的技术认识，区分真实实验、CPU 契约验证和待执行计划。实验完整图文及原始数据留在本机，GitHub 保存源码、协议和精简结论。**目前尚未证明详细触觉带来可靠、独有的任务收益。**

## 1. 数据可用不等于监督正确

早期工作首先暴露的是时间对齐问题：视频的 50 FPS 标签不能代表实际物理采样时刻。相机、关节状态、触觉窗口和执行动作必须来自同一回合，用 physics step 连接，并通过来源与完成清单审计。当前输入只能读取过去接触；未来动作作为监督，不得把未来力信号放入输入。

固定长度 H50 标签在轨迹尾部会越界。实现采用有效位置掩码和截尾处理，禁止将补齐部分当真实专家动作。失败规划、场景初始化不稳定、真实操作失败、基础设施中断有不同含义；缺失终态记为未知，不伪装成任务失败，也不悄悄换 seed。

## 2. 模型加载一致性是对照实验的前提

154800 主模型加载期间曾出现非持久缓冲区与独立进程推理不一致的问题，因此旧版效果解释不能沿用。补齐缓冲区恢复和确定性检查后，才执行正式适配器训练。原模型与 checkpoint 保持只读，修改放在隔离副本和研究仓库。

当前主模型约 6B 参数、BF16 冻结；训练的是 65,664 参数的 FP32 触觉适配器。检查不仅看 loss 是否下降，还确认主模型没有梯度污染、实际输入经过适配器，以及历史节点是否精确复现。

## 3. 从初步提升到更强负对照

CWMJ 瓶子替换改善了场景初始化稳定性，但改变了资产分布。因此结论限定于该替换场景，不能直接外推原始多瓶分布或真实硬件。

M6 扩充到 7 条成功训练轨迹、402 个窗口；独立验证固定 40 个窗口。闭环确认预定 16 个新 seed、3 个训练重复、4 个条件，共 192 回合；实际 191 个终态和 1 个未知中断。按既定规则整 seed 排除后，15 个独立 seed 参与主要统计。

| M6 条件 | 成功次数 / 完整回合 |
|---|---:|
| 零触觉训练 | 9/45 |
| 真实触觉训练 | 22/45 |
| 错配触觉训练 | 21/45 |
| 真实触觉权重、推理输入置零 | 0/45 |

真实触觉相对零触觉提高 28.89 个百分点，但 Holm 校正 p=0.10156，未通过预登记稳定收益标准。相对错配只提高 2.22 个百分点。输入置零明显恶化不能直接证明真实触觉信息有效，因为它可能制造训练与推理分布偏移。

更关键的认识：错配供体按“是否接触”分层，仍携带接触状态信息，不能称为完全无信息对照。因此 M7 增加仅保留接触状态位的条件，去掉详细力幅值、左右侧和时间次序信息。

| M7 条件 | 成功次数 / 回合 |
|---|---:|
| 零触觉训练 | 6/48 |
| 真实触觉训练 | 14/48 |
| 错配触觉训练 | 16/48 |
| 接触状态位训练 | 14/48 |

M7 的 192 回合全部有终态，16 个独立 seed 完整。真实触觉相对接触状态位差为 0，95% seed 簇 bootstrap 区间为 [-8.33, 8.33] 个百分点；相对零触觉差为 16.67 个百分点，区间 [-2.08, 37.5]，Holm p=0.375。仍未证明详细触觉的独有收益，也不能把“未显著”解释成两种方法等效或所有触觉都无效。

独立统计单位是环境 seed；同一 seed 的 3 次训练重复先平均，不能当成 48 个独立环境样本。成功门、缺失规则和多重比较校正应在运行前固定。

## 4. 训练量不足：将猜测变成 M8 实验

“训练步数少”与“独立数据少”是两个问题。402 个窗口来自 7 条轨迹，彼此相关；平衡有放回采样的 720 次抽取也不是严格两轮遍历。多训练可能改善拟合，但不能凭空增加场景和失败模式覆盖。

M8 固定数据、初始化、采样规则和优化器，将 4 条件 × 3 重复分别连续训练至 2880 步，保存 720/1440/2880。720 节点必须与历史权重张量及验证结果精确一致；中途验证恢复随机数、模式和 cache 配置，避免改变后续训练轨迹。闭环预留新 seed 100103–100118，比较 720 与 2880，共计划 384 回合；1440 仅用于离线描述，不挑最好节点。

本次归档时，首轮 zero、true、mismatch 的 2880 节点及曲线报告已生成，其余训练由后台继续；尚无 M8 完整闭环结论。恢复开发和受控反馈实验也不能写成已完成的真实效果验证。

## 5. micro-batch、global-batch 与显存利用

当前单卡 micro-batch=1，梯度累积=1，因此 global-batch=1；每个训练窗口更新一次。AdamW 学习率 1e-4、weight decay 0.01、梯度裁剪 1.0。已完成首轮三组训练记录的峰值 PyTorch 分配显存均约 13.69 GiB；一次实时 GPU 观察为约 12.5 GiB、利用率 90%。瞬时占用、分配峰值与设备总占用不是同一个指标。

显存有余量，值得后续单独测 micro-batch 1/2/4 的样本吞吐和峰值显存；目前没有实测 batch 2/4，不能承诺加速。梯度累积提高有效 batch，却不会自动提高并行吞吐。提高 batch 还改变每次更新的数据量，比较时需同时报告样本曝光量、优化步数和耗时，而非仅比较相同步数。

M8 正在检验训练时长，且有历史精确复现要求，因此本轮不半途改 batch。后续吞吐测试与科学效果实验分开登记，再统一选配置。

## 6. 自动化与本地分析

实现训练队列、训练结束后的评测衔接、逐回合图文、完整性与成对审计、汇总统计，以及本地 Strata 分析待办。队列锁、输入 SHA、独占输出目录和终态检查用于避免重复执行；部分产物和异常要保留审计，不能静默重跑覆盖。

Strata 仅在服务已运行且模型已加载时调用，使用自己的 GPU 租约，保存请求、输入 SHA 与原始响应。服务不可用时保留待办，绝不自动重启。当前尚未验证真实 Strata 分析调用，CPU 模拟接口通过不等于真实模型分析完成。研究者等整套流程结束后集中复核，减少重复云端分析。

## 7. 后续问题与边界

恢复开发使用独立开发 seed 100119–100122，对比原专家与一次开爪干预后的重规划。监督片段不能跨越外部干预；只有来源审计和真实完成条件通过后，才讨论后续训练准入。代码及 CPU 契约已实现，真实恢复实验仍待运行。

受控反馈方向拟比较每 1 与每 10 动作重新观察。已有 M7 诊断中，相邻请求的物理间隔中位数约 3.336 秒，而触觉历史约 100 毫秒，提示信息可能在动作块内过时；这是设计动机，不是效果证据。公平噪声应按实际执行动作位置对齐，而非按请求次数对齐；新确认 seed 和完整协议仍待固定。

仿真 impulse/dt 是未校准代理，不能当真实夹爪力限。离线误差下降、控制信号改变、某个 seed 成功，都不能代替独立闭环任务收益证据。

恢复开发 v1 的 8 场已经结束，四对均未通过技术配对门。两个完整配对从第一条命令开始就出现差异，早于开爪干预；另外三个未知终态来自右臂规划异常。初始 RGB 与关节向量相同不足以保证规划轨迹相同。CuRobo 使用独立随机设置，任务里 Python random.seed 被注释只是线索，不能据此宣布根因已确认。v1 数据继续禁止训练准入。

新开发 seed 固定为 100123–100126，不复用确认集、不进入未来训练或独立测试。44 项恢复相关 CPU 测试通过后冻结实施清单；11 月 8 日 13:37 已启动独立后台批次并确认首进程持有自有 GPU 租约。此处记录的是启动事实，不是开发通过或触觉模型获益。四对结果仍须按冻结门槛审计。

下一阶段应把恢复示范质量与模型效果分开验证，并完成受控反馈实验。更大 micro-batch 的吞吐基准仍未执行，不将显存余量直接等同于已获得训练加速。Strata 辅助分析也不能在未调用或未完成时写成完成；它不决定官方成功标签，且不得自动启动或加载。

## 2026-11-08：受控反馈试运行与batch基准准备

受控反馈技术试运行已在后台执行，固定两开发seed、四条件和两种反馈频率，共16场；尚未完成全批技术审计，不能宣称高频触觉有效。正式确认候选方案独立使用新seed、三个既有训练重复和固定2880步权重，将频率与触觉条件交互作为预定对比，不根据试运行成功率挑选配置。候选seed的6228份本机JSON元数据审计未见冲突；该范围不包括未登记试验，仍非执行许可。

显存没用满不意味着直接把batch改大即可。实际模型动作loss按有效joint_mask总数归一化，而MoE序列平衡和router-z辅助项按序列/token平均。尾部有效长度不同，统一除以累积次数会改变动作目标权重；按动作数缩放整个total_loss又会错误缩放辅助项。新的独立基准分别按有效坐标数和样本数加权，拒绝不支持的辅助归约配置。

全CPU重建442个样本（训练402），与历史数据指纹一致。固定32个训练窗口后，micro1/2/4均通过真实输入打包。六项CPU测试涵盖尾部mask、不同有效长度的loss/梯度、相机与触觉样本顺序、数值比较失败路径。GPU基准runner、有限队列和中文图文报告器已实现，并固定BF16工程容差及起始参数/teacher/noise哈希核验。三个配置global-batch统一4，各计时8次更新；它测吞吐，不是新一轮触觉效果训练。GPU实测尚未启动，必须等反馈队列全部终态且GPU空闲；不覆盖checkpoint，不自动操作Strata。
