# M6 多随机重复正式适配器训练与独立确认协议

冻结时点：M6固定16次采集全部结束，5个新增train、4个新增validation通过源审计；任何本轮模型拟合和新确认seed仿真之前。M4/M5结果已知，属于方法开发证据，不能充当本协议的独立确认。

## 数据与训练预算

训练：旧CWMJ train100045/46显式合并新增100058/62/64/65/66，共7个seed。验证：历史validation100049单列，加新100067–70共4个。旧原20瓶场景不混入；M4/M5测试51–54不入训练；确认100071–86始终保留。完整数据字节SHA、分组与collection gate绑定training_manifest.json，每次训练重新验证。

3次训练随机重复r=0,1,2，每次zero、true、mismatch三臂各720步，共6480优化步。不选最佳重复或最佳验证checkpoint，固定最后720步全部进入后续报告。每次重复内共用归一化、初始化、采样顺序、流噪声、教师补全及评估噪声。

- 冻结154800基座、恢复非持久buffer、停用不可复现eval-only MoE路径；原源码/原checkpoint只读。跨进程一致性SHA门仍必需。
- 65,664参数适配器FP32、基座BF16；AdamW lr1e-4、weight_decay0.01、batch1、clip_grad_norm1，分配显存上限22GiB。
- 每次重复适配器CPU FP32初始化seed=98101+r；输出投影严格零，训练归一化buffer保留；记录参数SHA证明三次初始隐藏参数不同。不会把原基座重新初始化。
- 均匀抽训练seed，再均匀抽接触/非接触层与其中窗口；采样RNG=98201+r。流训练噪声每步seed=990000+10000*r+step（step从0起）。各臂顺序完全相同。
- 所有有效训练窗口都可被抽样；归一化仅用训练数据。mismatch donor为另一训练seed同当前过去接触层，frame-index确定性映射，不读取目标，验证从不供体。
- 缺失H50尾部与未监督关节采用冻结当前观测教师补全，未知标签不参与loss；终止长度不进入推理。各重复教师noise=71000+训练样本index，固定方法，不视作真实未来标签。
- 推理评估10步去噪，每验证seed按预设接触/非接触各4个等距窗口，noise=81000+样本index。同true权重另做输入zero/mismatch干预；本轮不做mean时序主张。

每重复的离线信息支持门：所有4个新验证seed接触MAE，true至少比zero及mismatch均低5%，且输入zero或mismatch均使true变差。旧49只报告、不作为新验证门。三次重复均通过才称可重复离线线索。MAE不等价任务成功，离线不通过也执行预定独立闭环，不挑有利重复。

## 独立闭环确认（模型固定后实施）

固定新seed100071–100086共16个，各重复均评估四条件：zero训练/zero输入、true训练/true输入、mismatch训练/跨训练回合mismatch输入、true训练/zero输入。共16×3×4=192回合，按seed、重复、上述条件顺序串行。模型始终是最后720步权重，不根据验证或前几回合成绩更改。

统一CWMJ v2资产、原400实际动作成功判据、每10动作重规划、10步去噪、无temporal ensemble、noise=seed*100+request_index；1200秒仿真段墙钟/60000物理步资源截断单列。初始化拒绝不换seed，不作为完整失败。

运行时mismatch在有效窗口时，按request_index取排序训练seed列表的模索引，再在该供体训练seed与当前过去接触同层的列表取模索引；只读取冻结训练输入，不用标签或测试未来。首个无效窗口保持当前明确invalid fallback。供体清单和字节SHA需随确认manifest冻结。真实输入与置零输入保留相同mask/age/valid。

技术门：每seed各条件起始三路RGB/14维状态相同，初始无效触觉下首10命令相同；同true权重两种输入在首次非零触觉前全部命令相同；权重、资产、模型源码、物理时钟分别核验。门失败暂停比较，不能算效果。

## 判定与统计边界

独立单位为场景seed，不把3个重复或动作窗口当独立seed。按seed先对3训练重复平均成功差，再汇总16seed；另列每重复结果与所有例外。至少12个seed具备全部条件和全部重复的完整技术有效配对，否则总体结论为数据不足，不补seed。

报告true相对zero训练、mismatch训练、同true权重zero输入的3个差值。描述性95%区间用seed整簇bootstrap 10000次、RNG=98601；配对双侧检验按seed整簇交换两臂（2^n枚举，检验对称性假设须说明），3比较Holm校正。稳定收益判据：对zero训练平均成功率至少提高10个百分点，对另外两条件差值均>0；3个差值的区间下界均>0且Holm校正p<0.05，并且每个训练重复的true-vs-zero差不为负。若不满足，报告未证明稳定收益/不确定或负结果，不继续筛seed追正结果。

成功回合动作数/物理时间只作次要描述，失败400动作不是成功完成时间。接触力为代理量，不能当真实安全握力或滑移标签。单种替换瓶几何不外推原比赛分布。

## 后续反馈频率与失败诊断

反馈频率审计不属于效果证明。更短动作块、更长触觉历史与专家恢复需另立协议，在相同视觉反馈频率下比较zero/true；不能在此192回合中途修改。专家失败日志已发现异常时动作阶段缺失，后续诊断重放可增加只读事件记录，但不能当新独立专家数据。
