# M7-A 仅接触状态训练协议 v1

目的：检验M6观察到的信号是否可能由接触状态解释。M6结论保持不变，新结果不得作为M6预登记结果。此协议固定训练；闭环执行前另冻结执行源码、最后权重、初始一致性检查及统计实现。

数据：完全复用冻结M6 training_manifest.json，7训练seed402窗口，5验证seed中相同40固定窗口；M6测试71–86永不进入训练。所有来源必须匹配m7_contact_state_source_audit.json及M6来源SHA。

训练：唯一新臂contact_state，三次重复r0/1/2，每次720步。基座154800 BF16冻结，65,664参数FP32适配器，AdamW lr1e-4、weight_decay .01、clip1、batch1。初始化98101+r，采样98201+r，flow噪声990000+10000r+step，教师71000+idx，验证81000+idx。复用M6正接触归一化（力通道输入全零，第三通道原尺度不变）。数据指纹与初始参数SHA必须逐重复精确匹配M6。未知H50尾部教师补全且不计loss。固定720步权重，不挑最佳或重跑成功重复。

转换：src/contact_state_control.py，只有过去有效窗口的任一有效位置正力代理量bit，广播到有效位置第三通道；其他通道零，coverage/age/valid保留。离线指标按seed/接触层报告first10 MAE，不设置事后离线收益门，不因结果调整闭环样本或挑权重。

新确认seed预留100087–100102（16个），三重复；四条件为既有M6真实触觉权重、新contact_state权重、既有M6无力权重及既有M6错配权重。所有四条件在新seed运行，总192回合；same-weight置零已在M6完成，M7主要比较true-contact_state及true-zero。依旧CWMJ v2、400动作、每10动作重规划、10步去噪、噪声seed*100+request；各组初始RGB/状态/首10命令必须相同。触觉bit可能改变归纳偏置，单臂差异不能解释为完整物理触觉机制。

主要统计单位seed，三重复先平均；至少12个完整可比seed。固定10000次seed簇bootstrap（RNG98701）及双侧精确配对sign-flip，两个主要比较Holm校正。预定“真实触觉超越接触bit且优于无力”门：两个成功率差均至少+0.10，两个95%区间下界>0，两个Holm p<.05，每重复两个差值均非负。true-mismatch作探索性描述，不得宣称其显著性。失败/中断分开，中断整个seed排除、不补选；不以任何结果提前停止。反馈频率与恢复扰动不在本批改变。

资源：单卡串行、自有租约、每重复训练硬时限3600秒、显存分配不超过22GiB；异常写failure记录，不覆盖现有模型或原checkpoint。不自动启动Strata。每重复完成即保存图文报告；闭环每回合同样报告。新确认seed在首次运行前仍需验证全局未使用。
