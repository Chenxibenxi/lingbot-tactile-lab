# 固定权重输入消融 v1：开发机制实验

问题：触觉历史数值在相同已训练适配器下，是否改变接触后的行为？此前zero与true分别训练，不能单凭二者动作分歧归因输入。

固定开发seed100145/100146，重复r0、训练步2880的true适配器；频率1/10；live/history_zero两输入，共8场。全部新目录独立运行，不把旧zero权重结果混入此对照。仍为两个开发seed，不作独立确认推断或选择最优seed。

history_zero只清零5×4×3历史，保留覆盖mask、年龄和valid。禁止用改valid、清mask或旁路适配器替代。live保持全部输入。两条件必须加载完全相同artifact SHA；冻结主模型、噪声按执行动作位置、H50、10次去噪、400动作、200000物理步、1200秒政策墙钟与1500秒外层超时。原始物理记录保持原值；另存实际送入模型的输入摘要。

复用完整预测块及逐动作实际qpos诊断，保存原RGB、物理接触对象、TOPP和原始终态。技术门要求初态与首动作配对、相同权重SHA、输入转换契约、同源时钟、无资源截断、每场完整图文。技术异常停止，不按失败填零。

预先分析：无非零历史之前，两条件在相同观测下输入应精确一致；检查首次输入分歧与首次命令分歧的时间关系。每seed/频率配对报告成功、桌面/瓶子接触占比、前60动作及接触后20动作的实际跟踪MAE、命令变化。所有指标都报告，不按成功挑子集。低频成功早停导致短窗口时明确缺失，不补齐。

解释：若差异在接触后才出现，支持历史数值在该权重下改变行为，但只有两个seed且非随机环境分布，不证明普遍收益。若两组仍同样失败，应优先检查基础适配器修正和控制推进；不能据无差异认定触觉永远无用。此消融不解决不同训练权重的基础残差差异，也不评估新的适配器结构。

状态：输入控制模块及保留元数据/不修改原对象/零历史等价测试已实现；独立运行入口、冻结清单和GPU执行尚未完成。旧诊断与正式384场文件不可更改。GPU仅用自有租约，不触碰Strata生命周期。

独立入口、逐场输入哈希审计与自动图文队列已实现，冻结后按固定8场执行；未知异常即停止，不重试。
