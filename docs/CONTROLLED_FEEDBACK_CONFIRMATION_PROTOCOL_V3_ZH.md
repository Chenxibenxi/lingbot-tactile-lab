# 受控反馈正式确认 v3：冻结执行协议

## 研究问题与固定设计

检验每1动作重新观察是否增强超出接触状态的真实触觉优势。独立环境seed为100147–100162；M8训练重复r0/r1/r2各自2880步权重；条件zero、true、mismatch、contact_state；频率间隔10、1。共384回合，顺序固定为seed、repeat、cadence10后1、上述四条件。不同条件均采用对应训练权重，同一条件在两频率间保持权重不变，不加入恢复数据或micro-batch基准参数。

骨干与原checkpoint只读。H50输出、10次去噪、原任务成功判据、CWMJ资产和qpos执行接口固定；每回合400真实动作、200000物理步、1200秒策略运行预算，启动器1500秒外层上限。推理期间仿真不推进，墙钟与物理时钟分开报告。相同动作位置的噪声为seed×1000+动作位置，错配供体按动作位置索引并保持既有接触分层规则，无true独有影子推理。

## 数据分工与技术门

确认seed不进入训练或验证；试运行seed100127/100128永久为开发用途，不并入本确认集。每个seed/repeat的8个条件/频率初始RGB、状态、场景及首执行命令须一致，后续动作允许分岔，不要求前10动作一致。逐回合复核真实物理接触、HDF5、时间线、频率、模型及供体SHA；不使用未来力信号。

正式冻结仅在技术试运行16场独立审计通过后进行，且必须记录候选seed冲突审计、实际容量估算及全部12份权重SHA。输出限本机专用存储目录，不删除既有数据。只使用自有GPU租约，不驱逐其他任务，不自动启动/加载/停止/重启Strata。

## 终态、缺失与固定分母

固定384回合、16个seed，不补选成功seed，不自动重试已开始回合。普通任务失败必须无资源截断、真实执行400动作且官方未成功；官方成功可早停。资源截断、初始化或推理失败、数据异常均为unknown，不填0。任何组合unknown或配对失败都关闭主要确认推断；保留固定分母和全部逐场图文。负结果与正结果同样可完成实验，不能以正结果为完成条件。

## 统计与判定标准

每个seed内平均三个训练重复，seed为独立单位。四个预定对比属于同一个Holm族：

1. (true−contact_state)间隔1 − (true−contact_state)间隔10。
2. 间隔1：true−contact_state。
3. 间隔1：true−zero。
4. 间隔1：true−mismatch。

每个正收益门同时要求效应≥0.10、seed bootstrap 95%区间下界>0、双侧精确符号翻转Holm校正p<0.05、三个训练重复的效应均非负。bootstrap10000次、固定随机种子98901。后三个对比全部过门才支持高频下独有触觉收益；第一个对比过门才支持反馈频率增强触觉优势，分别报告。

符号翻转依赖配对差值对称假设，bootstrap条件于三套既有权重；16seed不保证检验功效，不显著不等于等效或触觉无用。不得依据正式结果改权重、频率、seed、阈值或排除规则。

## 资源故障后的独立修复版

v2旧确认seed100129–100144永久排除，本次不合并其结果。仅因基础设施准入故障修复调度，保持权重、主要对比、阈值和样本量。启动前记录资源快照，获取自有租约后再次检查并记录原因；其他等待者或占卡导致暂停，不推进下一回合。仅连续正常完成的前缀可在恢复时跳过。已开始但技术失败的回合不自动重试，保留未知并暂停，需单独恢复协议。报告生成失败同样暂停，不改官方标签。每次恢复保留新的事件记录。
