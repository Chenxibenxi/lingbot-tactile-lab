# 同权重四条件开发验证 v1

固定seed100145/100146、r0/2880 true适配器、cadence10/1，条件live/history_zero/history_mismatch/contact_bit，共16场独立输出。复用固定主模型、H50、10次去噪、400动作、200000物理步、1200秒政策墙钟、1500秒外层超时及按执行动作位置配对噪声。不训练、不选择成功子集、不作为新独立确认集。

所有条件使用相同权重SHA。历史置零只改历史；错配只替换历史，保留当前mask/age/valid。供体仅来自冻结训练集，按当前有无接触分层、满足当前有效位置覆盖后，按排序列表以执行动作索引取模选择；无有效历史时保留原无效输入；无合格供体立即停止。contact_bit只保留窗口是否接触的单bit，不保留幅值、手指位置、顺序。训练供体源清单和代码须冻结。

每场重建实际输入哈希和供体选择，检查同权重、真实物理轨迹、预测前缀、时钟及初态/首动作配对，保留完整图文。技术异常不能按任务失败计分，不自动重试。

预定描述指标：每seed/频率四条件成功、首次桌面/瓶子接触、前60动作实际跟踪MAE、接触后20动作MAE、命令变化。明确成功早停与不同物理时间的局限；不足20动作不补值。若live优于置零但不优于错配或contact_bit，不能声称独有的对齐力信息收益。即使16场有正信号，仍需新独立seed、多训练重复和预注册统计确认。
