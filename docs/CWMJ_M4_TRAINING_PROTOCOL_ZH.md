# M4 CWMJ多 seed 训练对照预登记

在读取新验证集的模型预测之前冻结；数据采集 seed 列表见长期计划。只纳入完成并通过同源审计的回合，不依据模型误差选 seed。至少 2 个新训练成功 seed、1 个新验证成功 seed，且每个选中回合至少4个接触及4个非接触窗口；否则暂停本批拟合并报告原因，不能挪用验证或闭环 seed 训练。

仅使用全部合格CWMJ新训练100045–48及新验证100049–50。原场景train100023/36和validation26/27等均不混入；场景由scenario.json资产manifest与工厂SHA绑定。每个验证 seed 接触/非接触各固定均匀4窗口。所有训练窗口保留，优化抽样均匀选seed再均匀选接触/非接触层。固定360步，batch1，AdamW lr1e-4/weight_decay0.01，clip1，四组共享相同初始化、样本顺序、噪声/time。基座154800 BF16冻结，adapter FP32共65,664参数。新归一化仅全部训练回合正接触bins；末尾H50使用共同冻结教师completion、排除未知位置loss，终止长度不进入推理。此插补假设不变。

四组：zero（无力但保留mask/age）；true（真实过去触觉）；mean（对每手指按有效覆盖加权求5-bin时间均值，再广播回历史，保留mask/age）；mismatch（使用其他训练seed同接触层的确定性触觉donor，且验证回合绝不捐赠）。donor选取只依赖当前接触层、seed和frame索引，不读取动作目标。该对照用于离线归因，闭环只比较zero/true。记录donor映射。时间均值保留原始力代理均值，但不保证经log归一化后均值不变，须如实说明这一局限。

固定最后一步 checkpoint；推理10步去噪，主要离线指标为接触层前最多10条真实动作归一化MAE，另报全有效H50及非接触层。真正触觉信息的探索性支持要求每个新验证seed true均比zero及mismatch至少低5%，且true模型输入置零/错配恶化；时序支持另要求true比mean至少低5%，且时间均值干预恶化。所有条件分别报告，不能用时间信息失败否认接触统计信息，也不能把统计信息误报成时序学习。训练随机种子仅一个，仍不能给总体收益结论。

拟合前必须通过现有加载器SHA绑定的跨进程逐元素一致性门；训练全程检查基座无梯度、loss/梯度有限、22GiB显存上限、未知哨兵不影响forward。任何失败终止，不覆盖旧artifact。每个arm结束记录优化日志/权重SHA并形成图文小结，完整批次结束追加统一对照报告。主训练总timeout3000s，租约3600s；超时为未完成，不能改写成效果失败。

闭环预留51–54，两组各一次、400真实动作上限、10步重规划、同请求编号噪声、1200秒/60000物理步单独截断。初始化拒绝不补换。报告每seed成对结果、真实触觉干预、初始RGB/状态/首10动作一致性。四场景即使全部有利也只够下一阶段线索。
