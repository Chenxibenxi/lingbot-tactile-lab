# 受控反馈频率对照：实施设计，尚未冻结或启动

## 已核对的运行证据

只读检查M7第0训练重复、真实触觉条件的16个已完成回合：576次推理请求，中位单次推理墙钟0.7118秒，最大1.2937秒；最长回合墙钟85.30秒。相邻请求间隔共560个，中位834物理步、最小621、最大1701；以实际仿真dt约0.004秒计，中位约3.336秒。当前触觉窗口为25物理步、5个时间bin，即约0.1秒。因此采集连续触觉并不意味着策略持续接收触觉；两者需要分别描述。

这些是既有任务的诊断和运行预算证据，不证明增加反馈频率能提升成功率，也不能当新确认样本。仿真在模型推理期间不推进物理时间，墙钟延迟不能直接解释为硬件闭环延迟。

## 应隔离的干预

候选比较每1动作重规划与每10动作重规划。四条件zero、true、mismatch、contact_state使用各自同一份固定权重；不得边改变反馈频率边加入恢复训练数据。每个条件都提高重规划频率，避免将额外计算或更短开环执行本身误归因为触觉。

建议预先固定M8的2880步权重（三个训练重复），不是根据M8成绩挑最好checkpoint。模型H50输出、10次去噪、原任务成功判据、最多400真实动作、资产版本均相同。两个频率均在真实已执行动作数0、10、20……这些共有决策位置使用相同预定噪声种子；高频额外位置使用各自预定种子。不能只按请求序号配对，因为两频率的同序号已对应不同动作位置。

主要分析应比较触觉优势随频率的变化，同时报告高频下true相对contact_state及zero的差；以独立环境seed聚合训练重复。不得仅比较true自身高低频成功率就声称触觉因果收益。错配按接触层匹配仍保留接触信息，保持现有解释边界。

## 执行前仍需完成

分配未使用的新确认seed并冻结样本数、效应阈值和多重比较规则；目前未分配，不复用M6/M7/M8测试或恢复开发seed。先按当前推理预算验证400次请求能容纳于统一墙钟上限，不能让高频条件因超时大量截断再冒充失败。实际干预只在新的独立runner中实现，旧冻结文件只读。

记录请求实际物理步、窗口起止/有效性/年龄、每段执行动作数和推理耗时；验证相同频率内各条件初始无触觉命令一致，跨频率仅比较共享决策时刻的初始模型输出，不强求首10执行命令相等（高频会在其间重新规划）。最终逐回合图文与本地Strata辅助分析沿用自动流程，成功仍由仿真原判据决定。

本设计不修改正在运行的M8，也不立即占用GPU。恢复开发和频率对照各自有独立数据与协议，完成后才考虑联合训练实验。

## 2026-11-08 实施前补充

M8 已结束。根据全部 384 场的 11258 次请求，infer_seconds 中位数 0.6068 秒、95 分位 0.6795 秒、99 分位 1.0773 秒、最大 1.2650 秒。按每场最多 400 次请求估算，全部取既有 99 分位为约 431 秒，全部取既有最大值为约 506 秒。该字段包含现有代码中的请求处理/解码耗时，尚未包括 true 条件额外的影子零输入推理，也不包括全部环境执行、初始化、收尾和作图。因此这不是 1200 秒上限必然足够的证明；仍需独立、预登记的技术试运行。

正式高低频对照应统一关闭额外影子推理，或把相同的诊断调用施加给所有条件，避免只有 true 增加墙钟成本。当前倾向关闭确认回合中的影子调用，将条件有效性检查留在独立技术试运行，不根据正式结果决定是否补做诊断。

已实现 `controlled_feedback_schedule.py` 的动作位置噪声和执行数量契约，以及 `controlled_feedback_timing.py` 的窗口年龄记录。后者分别记录 capture 时、动作开始和结束时的触觉年龄；推理墙钟耗时与物理时间分开，历史有效性仍由原 valid_mask 决定，不能因有时间戳就推断有效。6 项 CPU 测试通过，但尚未接入实际 runner。

现有 M8 runner 的需要替换点已确认：噪声当前使用 `seed*100+request_index`，执行固定 `commands[:10]`；新 runner 应使用已执行动作位置驱动噪声与执行片段长度。错配 donor 的选择也应按已执行动作位置索引，在共有位置使用相同接触层选择规则，不复用请求序号造成额外混杂。模型权重固定为预先提出的 M8 2880 节点，不能因为其 true 结果较差而事后改选 720。

运行预算证据保存于本机 `data/reports/controlled_feedback_budget_diagnostic_v2.json`。后续 GPU 实施前还需检查磁盘容纳能力，预留确认数据空间；不得为了启动新实验自动删除既有评测证据。新 seed 分配与正式运行许可仍未冻结。
