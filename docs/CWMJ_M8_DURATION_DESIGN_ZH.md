# M8 固定数据训练时长对照（待冻结，尚未启动）

目的：检验 M6/M7 的 720 步训练是否限制触觉适配器学习。不能以出现正结果作为停止或完成条件。本阶段不增加训练数据、不改恢复监督、不改反馈频率、不解冻主模型。

## 已核验的出发点

训练集为 100045、100046、100058、100062、100064、100065、100066，共 402 个窗口。验证为 100049、100067–100070，沿用每 seed 八个固定窗口。采样器先均匀选 seed，再均匀选接触层，再有放回选窗口；720 步不是完整 epoch。三次 M6 重复分别只覆盖 336、330、325 个不同窗口，三个条件内顺序一致。训练损失含变化的样本和流匹配噪声，首尾均值不构成收敛证明。

## 固定比较

- 四条件：zero、true、mismatch、contact_state；三个配对初始化重复；记录 720、1440、2880 步节点。
- 沿用训练源、转换、归一化、错配供体、学习率 1e-4、AdamW、噪声规则和 10 步去噪；同一重复内四条件使用完全相同采样序列及噪声。长序列必须与已有 720 步序列前缀严格相等。
- 每个条件从固定初始化连续训练到 2880 步。节点保存独立权重和优化器状态，不覆盖旧产物。中间验证需保存并恢复随机状态及训练模式，避免改变后续轨迹。
- 720 节点先对照历史权重和固定验证输出。若不能复现，停止归因，定位原因；不得将实现变化冒充训练时长效果。
- 每个节点报告训练窗口覆盖率、各 seed/接触层暴露次数、验证误差（以 seed 为单位，接触和非接触分别列出）、训练损失与梯度、资源消耗。验证误差仅作为代理指标，不能替代闭环成功率。

## 闭环与判定（执行前仍需冻结清单）

主要闭环比较预先固定 720 与 2880 步，不根据验证结果挑选最好节点；1440 步用于学习曲线。采用全新独立 seed，并将三个训练重复作为配对重复而非额外独立环境样本。历史 M6/M7 测试 seed 已消耗，不进入训练、模型选择或新的确认样本。

主要估计为 true 相对 contact_state 的收益从 720 到 2880 的变化，以及 2880 步 true 相对 contact_state、zero 的收益；按独立 seed 聚合，给出配对区间和预先约定的多重比较处理。不能仅凭 true 自身成功率提高就认定触觉独有收益。正式运行前补齐未用 seed 清单、样本数、效应阈值、统计规则、源文件和权重 SHA、资源租约启动器及中断处理，并冻结清单。

## 实施检查

新建独立 runner 和报告器，不修改冻结的 M6/M7 文件。先验证长采样序列前缀、验证不扰动训练随机流、节点权重不覆盖及测试 seed 隔离，再执行 GPU 实验。GPU 启动前检查真实进程和自有租约，不驱逐其他任务，不自动启停 Strata。每个完成实验保存方法、数据、结果图、失败分析、局限和复现信息。恢复数据扩充仍是独立后续实验，不能混入本次归因。
