# 触觉训练前审阅卡：现为候选数据，不是训练授权

**当前决议：不得启动真实触觉模型拟合／发布触觉推理能力。** 研究路线仍是：先冻结原视觉基座，评审同回合专家示范及对照，再按租约做有界适配器训练，最后在原seed隔离的验证／测试折及闭环任务上比较。机器上的测试夹具即使造出 `training_approval=true` 也**不代表负责人批准**。

| 门 | 现有可核对证据 | 尚欠条件 |
|---|---|---|
| 来源 | [v2脱敏索引卡](<../datasets/relay_paired_training_index_candidate_v2.json>)：本机单3090、提锅5＋双瓶7成功规则专家，1361个因果当前RGB→下一专家14D对，已解码4083张相机图；逐样本私有索引留在Git忽略目录。旧v1 1112对逐行不变，新249只进双瓶训练候选。 | 仓库 `approved_paired_episodes=[]`；受控空夹失败和视觉策略自回放均不能当专家纠错标签；不取LXC旧字节补训练。 |
| 分折 | 提锅3训练／1验证／1测试；双瓶[v2](<../datasets/relay_pickdiverse_seed_split_candidate_v2.json>)5训练／原1验证／原1测试；总训899／验230／测232且原heldout未动。 | 每任务验证／测试各仅1个物理seed，无法量化泛化误差；需要独立、更丰富场景与自然失败覆盖。不得为了好看重抽旧测试。 |

| 资源与远程 | 本机唯一24GB RTX3090实行租约；原视觉26GB检查点不能再复制入研究仓库。Git远端已是私有仓库，但研究分支新提交仍待逐路径审核。 | 先审GPU峰值、冻结基座+仅训练小adapter的可行性；任何实验应遵守Strata恢复时限。`work/`审核清单须经负责人逐路径审阅后方可按命名路径推非main分支；原始数据、图片、权重与token绝不推。 |

**建议的下一次试验申请（未获批、不可直接运行）：**审阅成功示范的选择偏差及新样本覆盖→明确选择哪一版训练折、训练折归一化和固定测试集→把视觉-only／正确触觉／只打乱**过去**触觉三视图锁定同一图像、状态、14D动作与实际seed→先在空闲单3090下租约测只读载入/峰值，再限时少量适配器步数、保存只在私有`models/`的权重与SHA记录→离线评分只比较同折、同接触层，最后另计划真实闭环。任何阶段无权限、GPU繁忙、跨折、基线资产改动或没有可验证模型文件都停止。在线RL必须另先定义奖励防“握瓶到位就算放置”的漏洞，见[奖励风险](<ONLINE_RL_REWARD_RISK_ZH.md>)；真实硬件不在当前路线。
