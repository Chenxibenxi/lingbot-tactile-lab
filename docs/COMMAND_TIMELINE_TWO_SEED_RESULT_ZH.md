另一个重要执行时钟校验：[隔离的旧视觉策略真实自回放来源卡](<../datasets/relay_policy_self_rollout_154800_s100048_v1.json>)只作**控制周期诊断**，同一回合100个实际执行`take_action`的前后物理步差最小17、中位数86.5、最大181（dt≈4ms，中位数约0.346秒），没有一个恰好5、15或50步。这个选中过的视觉成功回合也不是规则专家纠错数据或一般成功率估计。因而不能仅看旧LeRobot 50fps或新专家每4ms命令侧录就断言“50个模型动作恰好1秒”；需另锁策略动作执行节奏与真实前向请求，再定义可训练H和时间采样。
