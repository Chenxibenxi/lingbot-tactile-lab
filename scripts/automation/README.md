# 自动化启动源码归档

这些文件是本机 `work/` 中已审计启动器的逐字节版本化副本；此次归档不修改运行中的文件，也不启动新任务。

当前脚本保留实验机绝对路径、固定 GPU 租约和本地冻结清单契约，不能视为任意机器开箱即用的入口。复现需要另行准备授权 checkpoint、同源数据、环境、资产和 `data/reports/` 清单；依赖的历史 work overlay 也只在实验机存在。不能仅复制启动器就宣称可复现实验。

恢复部署时先核对主机、所有源码 SHA、协议、数据清单和活进程，确认没有重复任务后，再将所需副本部署到清单规定的 work 路径。当前运行期间禁止覆盖 work 文件，禁止重新启动已有队列。Strata 只能调用已运行且已加载的服务，不自动启动或加载。
